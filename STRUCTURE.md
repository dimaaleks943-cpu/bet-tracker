# Структура проекта

Правила организации папок и файлов в `src/`.

## Общая структура

```
src/
├── api/              # Методы запросов на сервер
├── assets/           # Шрифты, изображения, статические файлы
├── components/       # Переиспользуемые компоненты
├── constants/        # Переиспользуемые константы
├── interfaces/       # Переиспользуемые интерфейсы и типы
├── pages/            # Страницы приложения
├── App.tsx           # Роутинг
└── main.tsx          # Точка входа
```

---

## `/components`

Содержит компоненты, которые используются в нескольких местах проекта.

**Правила:**
- Каждый компонент лежит в одноимённой папке.
- Файл компонента начинается с большой буквы: `Header/Header.tsx`.
- Интерфейсы, константы, хуки и хелперы, относящиеся только к этому компоненту, хранятся рядом в той же папке.

**Пример:**
```
components/
└── Header/
    ├── Header.tsx
    └── header.consts.ts      # опционально
```

---

## `/pages`

Каждая подпапка — отдельная страница приложения.

**Правила:**
- Главный файл страницы: `PageName/PageName.tsx` (с большой буквы).
- Внутри папки страницы может быть подпапка `components/` — компоненты, используемые только на этой странице.
- Рядом с файлом страницы могут лежать вспомогательные файлы:
  - `pageName.interface.ts` — интерфейсы страницы
  - `pageName.consts.ts` — константы страницы
  - `pageName.enum.ts` — перечисления страницы
  - `usePageName.ts` — хуки (имя файла = имя хука)
  - `helperName.ts` — хелперы (имя файла = имя функции)

**Пример:**
```
pages/
└── Statistics/
    ├── Statistics.tsx
    ├── statistics.interface.ts
    ├── generateChartData.ts
    └── components/
        └── BalanceTooltip/
            └── BalanceTooltip.tsx
```

---

## `/api`

Файлы с методами для работы с сервером. Из каждого файла экспортируются только методы.

**Правила:**
- Имя файла: `entity.api.ts` (например, `bets.api.ts`).
- Внутри — функции запросов (`getBets`, `createBet` и т.д.).
- Базовый URL и общие настройки — в `/constants`, не в api-файлах.

**Пример:**
```
api/
└── bets.api.ts
```

---

## `/interfaces`

Интерфейсы и типы, которые переиспользуются в нескольких частях проекта.

**Правила:**
- Имя файла: `entity.interface.ts` (например, `bet.interface.ts`).
- Интерфейсы, используемые только на одной странице или в одном компоненте, хранятся локально в папке страницы/компонента.

**Пример:**
```
interfaces/
└── bet.interface.ts
```

---

## `/constants`

Константы, переиспользуемые по всему проекту.

**Правила:**
- Имя файла: `entity.consts.ts` (например, `api.consts.ts`).

**Пример:**
```
constants/
├── api.consts.ts
└── routes.consts.ts
```

---

## `/assets`

Статические ресурсы: шрифты, изображения, иконки, локальные скрипты.

**Пример:**
```
assets/
├── fonts/
└── images/
```

---

## Именование файлов

| Тип | Формат имени | Пример |
|-----|--------------|--------|
| Компонент | `ComponentName.tsx` | `Header.tsx` |
| Интерфейс | `entity.interface.ts` | `bet.interface.ts` |
| Константы | `entity.consts.ts` | `api.consts.ts` |
| Enum | `entity.enum.ts` | `betStatus.enum.ts` |
| Хук | `useHookName.ts` | `useBets.ts` |
| Хелпер | `functionName.ts` | `generateChartData.ts` |
| API | `entity.api.ts` | `bets.api.ts` |

---

## Импорты

- Компоненты из `/components` импортируются по относительному или алиас-пути.
- Страницы не содержат прямых вызовов `axios` — только через `/api`.
- Общие типы берутся из `/interfaces`, локальные — из папки страницы/компонента.
